1️⃣ What is the difference between var, let, and const?
=> Var : A variable that can be redeclared and changed, and it is function scoped.
=> Let : A variable that cannot be redeclared but can be changed, and it is block scoped.
=> const : A variable that cannot be redeclared or changed, and it is block scoped.

2️⃣ What is the spread operator (...)?
=> Spread operator (...) expands elements of an array or object into individual elements.

3️⃣ What is the difference between map(), filter(), and forEach()?

=> map() : is used to create a new array by transforming each element of an array.
=> filter() :  is used to create a new array with elements that pass a condition.
=> forEach() : is used to loop through an array and perform an action, but it does not return a new array.

4️⃣ What is an arrow function?
=> An arrow function is a shorter way to write a function in JavaScript using the => syntax.

5️⃣ What are template literals?
=> Template literals are a way to create strings in JavaScript using backticks ( ` ` ) that allow embedding variables and expressions easily.
